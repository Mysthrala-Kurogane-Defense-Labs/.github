# Mysthrala Kurogane Defense Labs

**Ciberseguridad industrial para pequeñas empresas y microempresas de Bajo Deba y Euskadi.**

![Defensa de una pequeña planta industrial: fábrica, puesto de trabajo y controlador conectados dentro de un escudo](https://raw.githubusercontent.com/Mysthrala-Kurogane-Defense-Labs/.github/main/profile/assets/industrial-defense.svg)

MKDL trabaja sobre activos, accesos, incidencias y evidencias, con un alcance acordado y revisión humana. Kurogane Hub es la tecnología propia que apoya ese trabajo.

[Servicios y alcance](https://mkdl.jp/#trabajo) · [Contacto: info@mkdl.jp](mailto:info@mkdl.jp) · [Fundadora: Kalista / Tears Mysthrala](https://github.com/tears-mysthrala)

## Para empresas industriales

- **Diagnóstico delimitado:** mapa de situación y prioridades sobre una línea de control concreta.
- **Orden técnico y documental:** inventario, accesos, procedimientos y registros revisables.
- **Preparación de evidencias:** documentación para responder a requisitos de clientes y cadena de suministro.
- **Seguimiento acordado:** revisión de cambios, incidencias y acciones pendientes.

Para plantear un diagnóstico, indica el tipo de actividad, el problema que necesitas resolver y el alcance inicial. Envía información sensible por un canal acordado, fuera de las issues públicas.

El núcleo comercial de Kurogane Hub permanece privado. Los ejemplos públicos no acreditan resultados en clientes, compatibilidad con el núcleo privado ni preparación para producción. El trabajo de evidencias apoya la revisión de requisitos; la evaluación legal y la aprobación final requieren revisión humana.
